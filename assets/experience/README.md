# Company logos

Optional. Drop a PNG here and it replaces the lettermark placeholder in the
Experience section of `index.html` — no code changes needed.

| File | Organisation |
|------|--------------|
| `cyan.png` | Cyan Robotics |
| `cruise.png` | Cruise LLC |

Square-ish, ≥ 180 × 180, transparent background works best — they render inside
a 90 × 90 white box with `object-fit: contain`. See `assets/education/` for
examples of the same treatment.

Paths are declared via `data-img-src` on each `.cv-logo` in `index.html`.
